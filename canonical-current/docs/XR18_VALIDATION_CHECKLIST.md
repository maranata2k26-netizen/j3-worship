# XR18 physical validation checklist

This checklist is intentionally marked **NOT YET PHYSICALLY VALIDATED** in this environment.

1. Install current XR18 Windows ASIO driver on test PC.
2. Confirm J3 can enumerate XR18 ASIO inputs/outputs.
3. Run at 48 kHz with 256, 128 and 64 frames where stable.
4. Verify 18 simultaneous inputs and intended USB return paths.
5. Confirm PA master receives no Click/Guide under Safe Mode.
6. Confirm independent IEM outputs and Copy Mix.
7. Record all selected inputs for an extended test and verify files.
8. Disconnect/reconnect USB and confirm safe failure/recovery.
9. Test CPU stress, VST3 latency, bypass and crash quarantine.
10. Produce J3 Diagnostic Report with measured latency/dropouts.
